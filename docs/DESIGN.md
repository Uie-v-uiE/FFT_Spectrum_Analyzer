# DESIGN — k5p-fft-accelerator(Radix-2 SDF 流水线 FFT 处理器)

目标器件:xcku5p-ffvb676-2-i(RK-XCKU5P-F V1.2)。方法学:《FPGA 高性能·低资源架构设计路线图》闸门 G1–G5。

## 1. 指标(阶段 0,全部数字化)

| 指标 | 数值 |
|---|---|
| 变换长度 N | 64 / 256 / 1024 / 4096(2^M,M=6..12,参数化) |
| 吞吐 | 1 复样本/拍;@400 MHz = 400 MSPS(16-bit I/Q,12.8 Gb/s) |
| 数据位宽 | 输入 16-bit 有符号 I/Q;内部 17-bit(1 位保护位);输出 17-bit I/Q |
| 旋转因子 | 18-bit 有符号,量化步长 2^-17 |
| 帧率 | 连续帧背靠背,无帧间隙(纯流水,valid 永不气泡) |
| 精度闸门 | 与比特精确模型逐位一致;与 numpy 浮点 FFT 的 SQNR 报告备案 |
| 输出序 | 位倒序(缺省)/ 自然序(可选重排序缓冲) |
| 接口 | AXI4-Stream(s_axis/m_axis,tdata={im,re}),TUSER 帧起始透传 |

## 2. 吞吐与算子反推(阶段 1,路线图 1.2 节公式)

N_op = R_sample × K_ops / (f_clk × η)。R2SDF 架构每级 1 个流水复乘、每拍处理 1 样本,
N=4096(M=12)共 12 级,其中最细 2 级(W₂/W₄)是平凡旋转({±1,±j},交换/取负实现,0 DSP),
复乘级数 K = M−2 = 10;3-DSP 高斯复乘 → **30 DSP**。400 MHz 下 DSP 利用率 30/1170 ≈ 2.6%,
吞吐上限即 f_clk(流水 II=1),瓶颈为时钟而非算子 → 计算受限区,架构成立。

延迟:流水填充满 N 拍(含各级延迟线),输出延迟 = N + M·L_cmult + 常数,由周期模型实测。

## 3. 架构(阶段 3)

DIF(按频率抽取)SDF,输入自然序 → 输出位倒序。层级 ℓ = 0..M−1(0 为最粗分
裂),级内:

```
        ┌───────── 延迟线 SR(D−Lc) ─────────┐
x_in ──┬─┤(前半块存原始)                      ├─┬── 前半块:输出 SR 中的上一块 diff·W
       │ └────(后半块存 diff·W)──────────────┘ │
       │        ↓ SR_out = x_in 延迟 D 拍      │
       └──→ BF2(a±b) ──→ a+b ───────────────────┴─→ 下一级(后半块)
                │
                └→ a−b → CMULT(W_N^(2^ℓ·n)) ──→ >>1 舍入 ──→ 回填 SR
```

- 块节奏:级 ℓ 的输入按长度 BL=N/2^(ℓ−1) 分块,块内前半拍存数、后半拍配对;
  级输出 = [前半拍:上一块的 diff·W | 后半拍:a+b],天然完成子变换交织,
  级间零胶合逻辑、零 FIFO。
- 延迟线长度 D−Lc(D=N/2^(ℓ+1),Lc=复乘流水级数 3):diff 在后半块算出、下一块前半
  拍 emerges,总行程恰为 D 拍。SR 无复位 → SRL/BRAM 映射。
- 缩放:每级 diff·W 输出右移 1 位 + convergent 舍入;位宽账:级输入 w → 加法路 ≤2|x|
  (w+1),乘积瞬态 ≤2.83|x|(w+2,在 48-bit DSP P 内)→ 移位后 ≤1.42|x|(w+1)。
  全流水恒定 17-bit,无溢出(证明见 VERIFY.md)。
- 平凡级(ℓ=M−2:W₄={1,−j},ℓ=M−1:W₂={1}):直连交换/取负,省 DSP。
- 复乘(3-DSP 高斯):k1=br·(ar+ai)(DSP 预加器),k2=ai·(br+bi)(B 路进位预加,
  1 级流水),k3=bi·(ar−ai)(DSP 预加器);re=k1−k2,im=k2+k3。对比直积 4-DSP 省 25%。
- CMULT 流水 Lc=3:周期 0 ROM 出数,1 预加/B 寄存,2 M 寄存,3 P 寄存,4 舍入寄存。

## 4. 资源账本(G1,预算 vs 上限,路线图 2.4 红线)

N=4096,全部取上界估算:

| 资源 | 估算 | 红线(器件) | 依据 |
|---|---|---|---|
| DSP48E2 | 30(10 复乘 ×3)+ 余量 4 = 34 | 80%(936) | 3-DSP 高斯 |
| BRAM36 | ≤8(旋转因子 ROM:ΣD≈N/2·(1+1/2+…)=N−2 点 ×36b;N=4096 → 4094×36b ≈ 4 块;+重排序 2 块) | 80%(432) | 36Kb/块 |
| LUT/FF | 各级 BF2(17b 加减)+ 舍入器(17b)+ ROM 控制器 + AXI-S skid;估 <3K LUT | 70%(165K) | 手册推算 |
| 控制集 | 数据通路无复位无使能,仅 IO/valid 链用 CE;预期 <10 | 7.5% | report_control_sets 实测 |

结论:资源宽裕,无需并行展开;设计重心在 **Fmax**(目标 400 MHz,冲刺 450)与位精确验证。

## 5. 时钟与复位

- 单时钟域 `clk`(OOC 验证约束 2.5 ns = 400 MHz);板级演示顶层用板载 200 MHz 差分时钟
  + MMCM 生成 400 MHz,复位由 reset_synchronizer 同步释放(2-FF + max_fanout)。
- 数据通路无复位;复位仅作用于 IO skid buffer 与 TUSER/帧计数逻辑。

## 6. 板级演示顶层(上板用,用户执行)

ROM 内置一帧合成信号(双音),FFT 后逐帧取峰值 bin,LED[3:0] 显示峰值 bin 低 4 位、
随帧闪烁作活性指示。综合/实现由 `scripts/build_board.tcl` 一键完成。
