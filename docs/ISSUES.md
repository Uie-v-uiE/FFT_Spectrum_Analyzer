# ISSUES — k5p-fft-accelerator

发现的问题与处置记录。状态:OPEN / FIXED / WONTFIX。

## FIXED

### I-01 旋转因子符号约定错误(G2 建模期)
- 现象:与 numpy 对不齐,奇偶 bin 全错。
- 根因:W_N^k = e^{−j2πk/N} = cosθ − j·sinθ,θ 取正角;初版对 θ 又取了一次负号,
  s_q = −sin(−θ) = +sin(θ),等价于全体旋转因子共轭。
- 处置:θ 取正角,c=cos θ、s=−sin θ,并钳位到 18bit 有符号(cos0° → 2^17−1)。

### I-02 DIF 差路径符号反(G2 建模期)
- 现象:偶 bin 对、奇 bin 全错(M=3 手推发现)。
- 根因:DIF 蝶形 d = a − b,a 为先存样元(早 D 拍);代码写成 x_now − partner = b − a。
- 处置:d = partner − x。

### I-03 Python 元组真值陷阱导致 SR 选择器失效(G2 建模期)
- 现象:冲激能量逐级丢失,每级只剩加法路一路有值。
- 根因:`fh_hist` 存相位标志为元组 (1,0)/(0,0),`if fh_f` 对非空元组恒真,
  SR 输入多路选择永远选 raw 路,diff·W 数据从未写入延迟线。
- 处置:取 `fh_f[0]` 位作选择信号。教训:**建模代码里用纯 int/bool 作控制信号**。

### I-04 台架停拍语义错误(G2 建模期)
- 现象:stall 不变性断言失败(无 stall 时全对)。
- 根因:gap 循环里帧内指针 `i` 照常自增,停拍那拍的样本被跳过,输入序列随停拍变化。
- 处置:停拍期间保持当前样本,仅 adv 时 i+1。

### I-05 校验分支旋转因子共轭(核心 bug,G2 建模期)
- 现象:scaled 模式 SQNR = −3dB;置换经验提取与浮点模式"自洽地"得到一套怪异闭式,
  与定点模式对不上;M=3 单音能量出现在错误的 bin 槽位。
- 根因:浮点校验分支复乘写为 y=(dr·cr+di·ci, di·cr−dr·ci),展开即 d·conj(t),
  而 t=cr+j·ci=W —— 整个校验模型在算共轭核变换。定点路径(W 正向)与校验路径
  (W 共轭)各自自洽,但蝶形加/减路承载的 bin 子集随核方向改变,
  输出置换随之改变,造成"同一结构两种置换"的假象。
- 处置:统一为 y=(dr·cr−di·ci, dr·ci+di·cr)。修正后置换回归标准位倒序,
  全精度误差 1e-14,SQNR 74.2/68.4/62.3/56.2 dB。**教训:双模型互验时,
  任何"各自自洽、互相矛盾"的现象,优先怀疑两模型对同一数学对象有不同约定。**

### I-06 经验置换提取的块对齐假设(G2 建模期)
- 现象:全 bin 验证失败。
- 根因:假设 bin0 位于输出块位置 0(对)但验证下标写成 base+N+pp(错位一块);
  且 DC 容差 0.6 未覆盖 6 级舍入累积(±3)。
- 处置:验证本块 base+pp;DC 容差放宽到 8;DC 定位 + p0 全扫描。

### I-07 舍入偏置权重与低场双重错误(已修)
convergent 位 ((x>>s)&1) 权重为 1(加在最低位),初版放在 bit[s](权重 2^s),
且低场误写 2^s−1(应 2^(s-1)−1)。单元 8192 例对拍捕获,解析重证。

**结构性根因(已定位,修复待实施):**

L1 丢 1@模型下标 48、L2 丢 2@56、L3 丢 3@60、L4 丢 4@62、L5 丢 5@63

故 RTL 需要的对齐 = PINIT=0(L0)/相位补偿(L1+)与 SR 写口微调的组合,
但 PINIT/SRD/管深(3/4 级)共 12+ 种组合扫描均未同时满足 L0..L5,
说明还存在一个未建模的 1 拍差(嫌疑:cmult 3 拍管 vs diff_pipe DLine(3) 的
边界语义、以及 TB 采集沿前/沿后语义)。
